# Library Management System

## Description

This is a simple Java project that demonstrates inheritance and method overriding using library items.

## Features

Display book details, including the author.

Display magazine details, including the issue number.

Display newspaper details, including the date.

Use inheritance to share common properties and methods.

Use polymorphism to display different item details.

## Project Files

LibraryItems.java – Base class containing the title and display method.

Book.java – Represents a book.

Magazine.java – Represents a magazine.

Newspaper.java – Represents a newspaper.

Main.java – Creates objects and displays their details.

## Run the program:

java Main

Concepts Used

Java Classes and Objects

Inheritance

Method Overriding

Polymorphism
